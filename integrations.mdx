## Google Drive

Connect your Google Drive to import AI-generated content from specific folders.

<Tabs>
  <Tab title="Web Setup" icon="globe">
    <Steps>
      <Step title="Authorize BosOn" icon="key">
        Visit `https://dashboard.getboson.app/integrations/drive` and sign in with Google.
      </Step>
      <Step title="Select Folders" icon="folder">
        Choose folders like "AI Outputs" or "Generations".
      </Step>
      <Step title="Enable Sync" icon="refresh-cw">
        Toggle auto-sync and set frequency (hourly/daily).
      </Step>
    </Steps>
  </Tab>
  <Tab title="API Method" icon="code">
    ```javascript
    // Use Google Drive API with BosOn webhook
    const { google } = require('googleapis');
    const drive = google.drive({ version: 'v3', auth: 'YOUR_OAUTH_TOKEN' });

    const res = await drive.files.list({
      q: "name contains 'AI-' and mimeType contains 'image'",
      fields: 'files(id, name, webViewLink)'
    });

    // Send to BosOn
    await fetch('https://api.getboson.app/v1/import/drive', {
      method: 'POST',
      headers: { 'Authorization': 'Bearer YOUR_BOSON_TOKEN' },
      body: JSON.stringify({ files: res.data.files })
    });
    ```
  </Tab>
</Tabs>

## ChatGPT and Gemini History

Pull images and files from your AI chat histories.

<Steps>
  <Step title="Connect ChatGPT" icon="message-circle">
    In BosOn Studio, go to Integrations > ChatGPT. Enter your OpenAI API key (`YOUR_OPENAI_API_KEY`).
  </Step>
  <Step title="Select Conversations" icon="search">
    Choose recent threads or filter by keywords like "generate image".
  </Step>
  <Step title="Sync Gemini" icon="google">
    Repeat for Google Gemini using your Gemini API key.
  </Step>
  <Step title="Review Imports" icon="check-circle">
    Assets appear in your Library under "AI History".
  </Step>
</Steps>

<CodeGroup tabs="ChatGPT,cURL">
  ```javascript
  // ChatGPT conversation export
  const openai = new OpenAI({ apiKey: 'YOUR_OPENAI_API_KEY' });
  const messages = await openai.chat.completions.create({
    model: 'gpt-4o',
    messages: [{ role: 'user', content: 'Generate image of perfume bottle' }]
  });
  ```
  ```bash
  curl -X POST https://api.getboson.app/v1/import/chatgpt \
    -H "Authorization: Bearer YOUR_BOSON_TOKEN" \
    -d '{"conversation_id": "chatcmpl-abc123", "api_key": "YOUR_OPENAI_API_KEY"}'
  ```
</CodeGroup>

## Desktop and Downloads Folder

Monitor your local folders for new AI outputs.

### Windows Setup

1. Install the BosOn Desktop app from `https://getboson.app/download`.
2. Select folders like Downloads or custom AI tool outputs.
3. BosOn scans for new files matching patterns (e.g., `*.png`, `*.mp4`).

<Expandable title="Advanced Folder Rules" default-open="false">
  Customize with regex:

  ```
  image: \.(png|jpg|webp)$
  video: \.(mp4|mov|avi)$
  ```

  Exclude temp files with `!temp_*`.
</Expandable>

## Email and WhatsApp Attachments

Import media from emails and messaging apps.

<Tabs>
  <Tab title="Email (Gmail/Outlook)" icon="mail">
    Forward emails to `imports@boson.app` or connect IMAP:

    ```bash
    # IMAP config example
    server: imap.gmail.com
    user: your.email@gmail.com
    password: app-password
    folders: [INBOX, AI-Generations]
    ```
  </Tab>
  <Tab title="WhatsApp" icon="phone">
    Export chats via WhatsApp Web > Export Chat > Attach to email > Forward to BosOn.
  </Tab>
</Tabs>
